使用说明与支持的格式

1. 选择手机里的 .cs 文件。
2. 选择输出范围并点击「开始解析」。
3. 如需中文说明，选择含中文的 Lua 参考文件。
4. 完成后点击「下载 output.lua」。

按照原脚本的规则识别 public class / public struct、// Fields 和 // Methods；成员行需要包含分号和 //，注释中需要有十六进制偏移量，如 0x10。这不是通用 C# 编译器。

选择参考文件后，字段中文说明根据参考文件中的名称匹配，优先匹配类名和字段名，其次使用含义唯一的字段名；不匹配时保留原文，说明仅供参考。中文写在注释中，不会改变原有数据。
同名字段或方法会生成重复的 Lua 键，读取 Lua 表时后者会覆盖前者。超大文件可能受到手机内存限制；建议处理时保持网页打开。

文件不会发送到服务器。首次打开网页需要联网；处理速度取决于文件和设备。
