使用说明与支持的格式

1. 选择手机里的 .cs 文件。
2. 选择输出范围并点击「开始解析」。
3. 完成后点击「下载 output.lua」。

按照原脚本的规则识别 public class / public struct、// Fields 和 // Methods；成员行需要包含分号、空格和 //，注释中需要有十六进制偏移量，如 0x10。这不是通用 C# 编译器。

同名字段或方法会生成重复的 Lua 键，读取 Lua 表时后者会覆盖前者。超大文件可能受到手机内存限制；建议处理时保持网页打开。

文件不会发送到服务器。首次打开网页需要联网；处理速度取决于文件和设备。
